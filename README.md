# 🔗 Short URL

A simple URL shortening REST API built with **Node.js, Express.js, and MongoDB**.

## 🚀 Features

- Create short URLs
- Generate unique short IDs
- Store URLs in MongoDB
- Redirect short URLs to original URLs
- REST API
- MongoDB local database

## 🛠️ Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JavaScript
